# Финальная проверка схемы именования

## Правила именования

1. Используется только латиница.
2. Все названия записываются строчными буквами.
3. Слова разделяются нижним подчёркиванием (snake_case).
4. Названия начинаются с буквы.
5. Таблицы называются во множественном числе.
6. Поля называются в единственном числе.
7. Идентификаторы заканчиваются на _id.
8. Зарезервированные слова SQL не используются.
