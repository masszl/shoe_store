# Анализ выполнения SQL-запросов
## 1. Цель работы
Изучить работу индексов в SQLite и проверить выполнение запросов с помощью EXPLAIN QUERY PLAN.

## 2. Проверка индексов

**Запрос 1. Поиск товаров по производителю**

```sql
EXPLAIN QUERY PLAN
SELECT * FROM products
WHERE manufacturer = 'Nike';
```

Результат: SEARCH products USING INDEX.

SQLite использует индекс для поиска товаров по производителю.

**Запрос 2. Поиск товаров по категории**

```sql
EXPLAIN QUERY PLAN
SELECT * FROM products
WHERE category = 'Кроссовки';
```

Для этого поля создан индекс idx_products_category. Результат выполнения запроса необходимо проверить отдельно.

**Запрос 3. Соединение заказов и пользователей**

```sql
EXPLAIN QUERY PLAN
SELECT o.order_id, u.login
FROM orders o
JOIN users u ON o.user_id = u.user_id;
```

Результат: SCAN o USING COVERING INDEX и SEARCH u USING INTEGER PRIMARY KEY.

SQLite использует индекс при просмотре заказов и первичный ключ для поиска пользователей.

## 3. Вывод

Индексы помогают SQLite быстрее находить нужные записи. EXPLAIN QUERY PLAN позволяет проверить, какие индексы используются при выполнении SQL-запросов.

На небольших таблицах разница во времени выполнения может быть незаметной.

## 4. Проверка изменения представления

Было создано представление v_simple, которое содержит
идентификатор товара и его цену.

При попытке изменить цену через UPDATE возникла ошибка:

cannot modify v_simple because it is a view

Это происходит потому, что SQLite не позволяет напрямую
изменять обычные представления без специальных триггеров.
