# Отчёт по практической работе №6

**Тема:** JOIN и агрегатные функции

**Проект:** shoe_store — магазин обуви

## Цель работы

Научиться объединять данные из нескольких таблиц с помощью JOIN, использовать агрегатные функции COUNT, SUM, AVG, MIN, MAX, а также GROUP BY и HAVING.

## Задание 1. Простые JOIN

**Запрос 1.** Выводит список заказов с датой и ФИО покупателя.

**Запрос 2.** Показывает названия моделей обуви и доступные размеры.

**Запрос 3.** Выводит заказы с именами покупателей и названиями купленных товаров.

**Запрос 4.** Показывает всех пользователей и количество оформленных ими заказов, включая пользователей без заказов.

## Задание 2. Агрегатные функции

**Запрос 5.** Подсчитывает общее количество пользователей с помощью COUNT.

**Запрос 6.** Вычисляет среднюю цену товаров с помощью AVG.

**Запрос 7.** Находит минимальную и максимальную стоимость товаров с помощью MIN и MAX.

**Запрос 8.** Рассчитывает общую выручку магазина с помощью SUM.

## Задание 3. Группировка GROUP BY

**Запрос 9.** Подсчитывает количество товаров в каждой категории.

**Запрос 10.** Вычисляет среднюю стоимость товаров каждого производителя.

**Запрос 11.** Показывает общую сумму покупок каждого клиента, у которого есть заказы.

**Запрос 12.** Подсчитывает количество проданных пар каждой модели обуви.

**Запрос 13.** Показывает количество товарных позиций для каждого размера обуви.

## Задание 4. Фильтрация HAVING

**Запрос 14.** Выводит категории, в которых больше трёх моделей обуви.

**Запрос 15.** Показывает покупателей, оформивших больше двух заказов.

**Запрос 16.** Выводит модели обуви, выручка от которых превышает 100 000 рублей.

## Задание 5. Аналитический отчёт

**Запрос 17.** Определяет три самых популярных размера обуви по количеству продаж.

**Запрос 18.** Находит пользователей, которые ни разу не оформляли заказ.

**Запрос 19.** Рассчитывает средний чек одного заказа.

**Запрос 20.** Определяет производителя, товары которого принесли наибольшую выручку.
