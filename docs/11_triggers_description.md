# Отчёт по УП.11 — День 11

**Тема:** Триггеры и аудит в SQLite.

## 1. Цель работы

Научиться создавать триггеры в SQLite, автоматизировать изменения данных и вести журнал аудита.

## 2. Созданные триггеры

В файле `db/triggers.sql` подготовлены шесть триггеров.

| Триггер | Назначение |
|---|---|
| trg_products_price_update | Записывает изменения цен товаров в audit_log |
| trg_orders_delete | Записывает удаление заказов в журнал |
| trg_users_updated_at | Обновляет дату изменения пользователя |
| trg_order_items_stock | Автоматически списывает товар со склада |
| trg_users_delete_protect | Запрещает удалять пользователей с заказами |
| trg_stock_items_insert_check | Запрещает добавлять отрицательное количество товара |

## 3. Отличие BEFORE и AFTER

**BEFORE** выполняется перед изменением данных. Используется для проверки и запрета неправильных операций.

**AFTER** выполняется после изменения данных. Используется для записи действий в журнал и обновления связанных таблиц.

## 4. Использование OLD и NEW

`OLD` содержит значения записи до изменения.

`NEW` содержит новые значения записи.

При изменении цены товара используются `OLD.price` и `NEW.price`, чтобы сохранить старую и новую цену в журнале.

При удалении заказа используется `OLD.order_id`, поскольку удаляемая запись уже не имеет нового значения.

## 5. Журнал аудита

Создана таблица `audit_log` со следующими полями:

- `log_id` — идентификатор записи.
- `table_name` — название таблицы.
- `operation` — тип операции.
- `record_id` — идентификатор изменённой записи.
- `old_value` — старое значение.
- `new_value` — новое значение.
- `changed_at` — дата и время изменения.

Журнал позволяет отслеживать изменения цен и удаление заказов.
