# Отчёт по УП.11 №10

**Тема:** Хранимые процедуры и функции.

## 1. Цель работы

Изучить создание пользовательских функций, работу с параметрами и транзакциями в SQLite и синтаксис процедур PostgreSQL.

## 2. Различия между функцией и процедурой

Функция используется для вычислений и возвращает результат. Процедура выполняет последовательность действий, например создание заказа или изменение остатков на складе.

В SQLite хранимые процедуры отсутствуют, поэтому для их реализации использовался Python.

## 3. Реализованные функции

**calc_order_total** — вычисляет стоимость позиции заказа умножением цены на количество.

**get_category_count** — подсчитывает количество товаров в выбранной категории.

**format_phone** — преобразует телефонный номер в формат +7 (999) 123-45-67.

Функции зарегистрированы в SQLite через метод `create_function()` и используются в SQL-запросах.

## 4. Реализованные процедуры

**create_order** — проверяет пользователя и остатки, создаёт заказ, добавляет позицию и списывает товар со склада.

**update_stock** — уменьшает остаток товара. Если количества недостаточно, вызывает ошибку и откатывает транзакцию.

**get_sales_report** — формирует отчёт по выручке за указанный период.

## 5. Транзакции

При создании заказа используется транзакция. Если возникает ошибка, выполняется `rollback()`, благодаря чему частично выполненные изменения не сохраняются.

При успешном выполнении используется `commit()`.

## 6. PostgreSQL

В файле `db/procedures_functions.sql` подготовлены примеры:

1. `CREATE FUNCTION` — функция расчёта стоимости.
2. `CREATE PROCEDURE` — процедура создания заказа.
3. `CREATE PROCEDURE` с `EXCEPTION` — обработка ошибки при недостатке товара.

Код PostgreSQL подготовлен для изучения синтаксиса и не выполнялся в SQLite.

## 7. Результаты проверки

После запуска `py src/procedures_functions.py` необходимо вставить фактический вывод программы: суммы заказов, количество товаров по категориям, форматирование телефона, проверку создания заказа, откат и отчёт по продажам.

## 8. Вывод

В ходе работы были изучены пользовательские функции, регистрация функций в SQLite, эмуляция процедур через Python и использование транзакций. Также был подготовлен SQL-код функций и процедур для PostgreSQL.
