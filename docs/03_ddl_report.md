# Итоговый DDL базы данных

В проекте используется СУБД SQLite.

Структура включает 7 таблиц: roles, users, products, sizes, stock_items, orders, order_items.

Для обеспечения целостности данных применяются PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, CHECK и DEFAULT.

Для связанных записей предусмотрены правила удаления RESTRICT и CASCADE. Дополнительно созданы 9 индексов.

Полная SQL-схема сохранена в `db/schema.sql`. Для проверки создания таблиц и индексов используется отдельная тестовая база.

Основная база `db/database.db` сохраняется без удаления.
