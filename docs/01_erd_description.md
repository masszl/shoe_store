# Описание ER-диаграммы «Чудо Обувь»

## Таблицы базы данных

### 1. roles
Хранит роли пользователей системы.
Первичный ключ: role_id.

### 2. users
Хранит данные пользователей: ФИО, логин и роль.
Первичный ключ: user_id.
Внешний ключ: role_id.

### 3. products
Хранит информацию о моделях обуви: название, категорию, производителя, изображение, состав, описание и цену.
Первичный ключ: product_id.

### 4. sizes
Хранит доступные размеры обуви.
Первичный ключ: size_id.

### 5. stock_items
Хранит количество обуви для каждой комбинации модели и размера.
Первичный ключ: stock_item_id.
Внешние ключи: product_id, size_id.

### 6. orders
Хранит информацию о заказах: дату и пользователя, который оформил заказ.
Первичный ключ: order_id.
Внешний ключ: user_id.

### 7. order_items
Хранит состав заказов: товарные позиции, количество и цену на момент заказа.
Первичный ключ: order_item_id.
Внешние ключи: order_id, stock_item_id.

## Связи между таблицами

1. roles → users (1:N)
Одна роль может быть назначена нескольким пользователям.

2. users → orders (1:N)
Один пользователь может оформить несколько заказов.

3. products → stock_items (1:N)
Одна модель обуви может иметь несколько размеров.

4. sizes → stock_items (1:N)
Один размер может использоваться у разных моделей.

5. orders → order_items (1:N)
Один заказ может содержать несколько товарных позиций.

6. stock_items → order_items (1:N)
Одна товарная позиция может встречаться в нескольких заказах.

## Вывод

ER-диаграмма состоит из семи связанных таблиц.
Для каждой таблицы определён первичный ключ, а связи реализованы через внешние ключи.

Структура позволяет хранить пользователей, товары, размеры, остатки и заказы без лишнего дублирования данных.
