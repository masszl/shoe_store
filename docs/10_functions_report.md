# Отчёт по практической работе №9

**Тема:** Пользовательские функции и процедуры в SQLite.

## 1. Цель работы

Научиться создавать пользовательские функции в Python, использовать их в SQL-запросах и работать с транзакциями.

## 2. Реализованные функции

| Функция | Назначение |
|---|---|
| calc_discount | Рассчитывает цену товара со скидкой |
| pluralize_items | Правильно склоняет слово «товар» |
| format_full_name | Преобразует ФИО в сокращённый формат |
| place_order | Создаёт заказ и уменьшает остаток товара |
| cancel_order | Отменяет заказ и возвращает товар на склад |
| get_client_tier | Определяет уровень клиента по сумме покупок |
| get_client_loyalty_days | Рассчитывает количество дней с первого заказа |

## 3. SQL-запросы

В файле `10_advanced_queries.sql` подготовлены пять запросов:

1. Вывод товаров с ценой и скидкой 20%.
2. Вывод ФИО клиентов без отчества.
3. Подсчёт количества товаров в каждом заказе.
4. Расчёт суммы заказа со скидкой 10%.
5. Определение уровня клиента, суммы покупок и срока обслуживания.

**Результаты выполнения:** сюда необходимо добавить фактический вывод программы `run_functions.py`.

## 4. Работа с транзакциями

Функция `place_order()` проверяет пользователя, товар и остатки на складе. После проверки создаётся заказ и уменьшается количество товара.

Функция `cancel_order()` удаляет заказ и возвращает товары на склад.

Для выполнения операций используются транзакции SQLite. Если при записи возникает ошибка, изменения откатываются.

## 5. Тестирование

Для проверки функций создан файл `test_functions.py` с использованием `assert`.

Проверяются обычные значения, пустые значения и граничные условия.

**Результат тестирования:** добавить фактический результат запуска `py src/test_functions.py`.

Также предусмотрен отдельный тест создания и отмены заказа на копии базы данных.
