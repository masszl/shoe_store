# Отчёт за день 3

Тема: определение типов данных и схемы именования.

В ходе работы проверены названия таблиц и полей базы данных магазина обуви. Использована схема именования snake_case.

Для таблиц определены ограничения целостности CHECK, NOT NULL, UNIQUE, PRIMARY KEY и FOREIGN KEY.

Подготовлены 9 индексов для внешних ключей и полей, используемых при поиске.

Проведены проверки некорректных данных. Восемь тестов CHECK завершились успешно. Проверки FOREIGN KEY, RESTRICT и CASCADE выполняются отдельным скриптом.

Подготовлен итоговый SQL-файл `db/schema.sql`.

Результат: подготовлена обновлённая структура базы данных для дальнейшей разработки.
