
# Результаты проверки SQL-запросов

## Цель работы

Проверить корректность данных и связей между таблицами базы данных shoe_store с помощью SQL-запросов.

## Запрос №1. Складские остатки

Используемые таблицы:
- stock_items
- products
- sizes

Запрос выводит название товара, размер, количество на складе и цену.

Ожидаемый результат: 10 складских позиций.

Фактический результат: не проверено.

## Запрос №2. Состав заказов

Используемые таблицы:
- orders
- users
- order_items
- stock_items
- products
- sizes

Запрос показывает номер заказа, дату, пользователя, название товара, размер, количество и стоимость позиции.

Ожидаемый результат: 6 позиций заказа.

Фактический результат: не проверено.

## Запрос №3. Общая стоимость заказов

Используемые таблицы:
- orders
- users
- order_items

Запрос рассчитывает стоимость каждого заказа с помощью SUM(quantity * unit_price).

Ожидаемый результат: 3 заказа.

Фактический результат: не проверено.

## Вывод

Подготовлены три SQL-запроса для проверки складских остатков, состава заказов и итоговой стоимости заказов.

Для объединения связанных таблиц используется JOIN, для расчёта стоимости заказов — SUM и GROUP BY.

После запуска запросов необходимо указать фактические результаты.
