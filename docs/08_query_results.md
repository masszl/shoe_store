# Отчёт по практической работе №7

**Тема:** Подзапросы и оконные функции

**Проект:** shoe_store

## Цель работы

Научиться использовать подзапросы в SQL, операторы IN, EXISTS, NOT EXISTS и оконные функции ROW_NUMBER, RANK, LAG.

## Задание 1. Скалярные подзапросы

**Запрос 1.** Выводит товары, цена которых выше средней стоимости всех товаров. Используется подзапрос в WHERE с функцией AVG.

**Запрос 2.** Находит покупателя, который оформил самый дорогой заказ. Используются вложенные подзапросы и функция MAX.

## Задание 2. Операторы IN и EXISTS

**Запрос 3.** Показывает покупателей, у которых есть хотя бы один заказ. Используется IN.

**Запрос 4.** Находит пользователей, которые ни разу не оформляли заказы. Используется NOT EXISTS.

**Запрос 5.** Выводит модели обуви, которые ни разу не покупали. Используется NOT EXISTS с проверкой связанных товарных позиций.

## Задание 3. Оконные функции

**Запрос 6.** Составляет рейтинг покупателей по общей сумме покупок. Используется RANK() OVER().

**Запрос 7.** Нумерует заказы каждого покупателя от старых к новым. Используется ROW_NUMBER() с PARTITION BY.

**Запрос 8.** Нумерует товары внутри каждой категории по убыванию цены. Используется ROW_NUMBER() OVER(PARTITION BY category ORDER BY price DESC).

**Запрос 9.** Находит самый дорогой товар в каждой категории. Используется табличный подзапрос с ROW_NUMBER().

## Задание 4. Накопительные суммы и сдвиги

**Запрос 10.** Выводит накопительную сумму заказов по датам. Используется SUM() OVER(ORDER BY).

**Запрос 11.** Показывает дату предыдущего заказа каждого клиента и разницу между покупками в днях. Используются LAG(), PARTITION BY и julianday().

## Результаты выполнения

Для каждого запроса необходимо добавить первые несколько строк фактического результата из SQLite Viewer.

На момент оформления документа выполнение запросов на базе данных не подтверждено.
