
# Отчёт по учебной практике. День 2

## Тема
Определение типов данных и работа с базой данных SQLite.

## Цель работы
Разработать структуру базы данных магазина обуви, определить типы данных и ограничения, создать таблицы и проверить их работу.

## Выполненные работы

1. Определены типы данных для всех таблиц.
2. Проведено сопоставление типов SQLite с типами демоэкзамена.
3. Определены ограничения NOT NULL, UNIQUE, CHECK, PRIMARY KEY и FOREIGN KEY.
4. Проверены правила именования таблиц и полей.
5. Создан файл db_init.py для инициализации базы данных.
6. Создана база данных database.db.
7. Созданы 7 таблиц: roles, users, products, sizes, stock_items, orders, order_items.
8. Разработаны тесты ограничений базы данных.
9. Подготовлен скрипт db_seed.py для заполнения базы тестовыми данными.
10. Созданы SQL-запросы с использованием JOIN, SUM и GROUP BY.

## Использованные технологии

- Python
- SQLite
- SQL
- Visual Studio Code
- Git

## Полученные результаты

Создана реляционная база данных магазина обуви.

Реализованы связи между таблицами и ограничения целостности данных.

Подготовлены скрипты для заполнения базы и проверки SQL-запросов.

Фактические результаты тестирования и количество записей необходимо подтвердить выводом программ.

## Возникшие трудности

При создании таблицы products возникла ошибка duplicate column name: category.

Также были обнаружены опечатки в названиях полей manufacturer и description.

Ошибки в структуре таблицы products были исправлены.

При заполнении базы возникла проблема с поиском размера обуви, так как значения размеров хранились в формате TEXT.

Для корректного сравнения использовано преобразование CAST.

В ходе практической работы изучены типы данных SQLite, ограничения целостности и связи между таблицами.
