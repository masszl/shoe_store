# Сопоставление типов данных

## 1. Типы SQLite и демоэкзамена

| Тип SQLite | Тип из демоэкзамена | Комментарий |
|---|---|---|
| INTEGER | INTEGER / INT | Целые числа |
| TEXT | VARCHAR / NVARCHAR | Строковые данные |
| TEXT (ISO 8601) | DATE | Дата в формате YYYY-MM-DD |
| REAL | NUMERIC / DECIMAL | Число с плавающей точкой |
| NUMERIC | NUMERIC / DECIMAL | Числовое значение |

## 2. Сопоставление 12 полей

| № | Поле | Назначение | Тип SQLite | Тип демоэкзамена |
|---|---|---|---|---|
| А | Идентификатор пользователя | Уникальный ID пользователя | INTEGER | INTEGER |
| Б | Фамилия пользователя | Фамилия | TEXT | VARCHAR |
| В | Логин пользователя | Логин для входа | TEXT | VARCHAR |
| Г | Дата заказа | Дата оформления | TEXT | DATE |
| Д | Наименование товара | Название обуви | TEXT | VARCHAR |
| Е | Путь к изображению | Адрес файла изображения | TEXT | VARCHAR |
| Ж | Размер обуви | Размер модели | NUMERIC | NUMERIC |
| З | Доступное количество | Остаток на складе | INTEGER | INTEGER |
| И | Цена товара | Стоимость обуви | NUMERIC | NUMERIC |
| К | Количество в заказе | Число пар обуви | INTEGER | INTEGER |
| Л | Цена позиции в заказе | Цена на момент заказа | NUMERIC | NUMERIC |
| М | Идентификатор заказа | Уникальный ID заказа | INTEGER | INTEGER |

## 3. Ответ в формате демоэкзамена

А — INTEGER
Б — VARCHAR
В — VARCHAR
Г — DATE
Д — VARCHAR
Е — VARCHAR
Ж — NUMERIC
З — INTEGER
И — NUMERIC
К — INTEGER
Л — NUMERIC
М — INTEGER

## Вывод

Для идентификаторов и количества используется INTEGER.
Для текстовых данных — TEXT в SQLite и VARCHAR в демоэкзамене.
Для дат — TEXT в формате ISO 8601 и DATE соответственно.
Для цен и дробных размеров обуви выбран NUMERIC.
