    # Проверка именования таблиц и полей

## 1. Правила именования

Для базы данных shoe_store используются следующие правила:

1. Все названия записываются латинскими буквами.
2. Используются только строчные буквы.
3. Для разделения слов применяется нижнее подчёркивание (snake_case).
4. Названия таблиц записываются во множественном числе.
5. Названия полей должны быть понятными.
6. Идентификаторы заканчиваются на _id.
7. Названия не должны совпадать с зарезервированными словами SQL.
8. Названия должны начинаться с буквы.

## 2. Проверка таблиц

| Таблица | Соответствует правилам |
|---|---|
| roles | Да |
| users | Да |

| stock_items | Да |

## 3. Проверка полей

Все поля базы данных соответствуют выбранным правилам.

Примеры корректных названий:

- user_id
- role_name
- first_name
- last_name
- product_id
- image_path
- order_date
- stock_item_id
- unit_price

## 4. Проверка ошибок

| Неправильно | Правильно | Причина |
|---|---|---|
| UserID | user_id | Использование snake_case |
| ProductName | name | Единый стиль названий |
| Order Date | order_date | Пробелы заменены подчёркиванием |
| 1product | product_id | Название не должно начинаться с цифры |
| StockItems | stock_items | Строчные буквы и snake_case |

## 5. Вывод

Названия всех 7 таблиц и их полей проверены.

Ошибок именования не обнаружено. Переименование таблиц и полей не требуется.
