# Проверка целостности данных

Для проверки ограничений используется отдельная тестовая база SQLite.

| Проверка | Ожидаемый результат |
|---|---|
| Пустое название товара | INSERT отклонён |
| Отрицательная цена | INSERT отклонён |
| Цена 1000000 и выше | INSERT отклонён |
| Логин короче 3 символов | INSERT отклонён |
| Размер обуви 55 | INSERT отклонён |
| Отрицательный остаток | INSERT отклонён |
| Нулевое количество в заказе | INSERT отклонён |
| Нулевая цена позиции | INSERT отклонён |
| Заказ с несуществующим пользователем | FOREIGN KEY отклоняет INSERT |
| Удаление пользователя с заказом | RESTRICT запрещает удаление |
| Удаление заказа с позициями | CASCADE удаляет связанные позиции |

Первые восемь проверок CHECK выполнены успешно. Результаты остальных проверок необходимо подтвердить запуском `py src/db_test_relations.py`.

Внешние ключи включаются командой `PRAGMA foreign_keys = ON`.
